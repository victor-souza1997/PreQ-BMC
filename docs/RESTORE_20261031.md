## 1. Mount this disk in another WSL (Windows 11, or Windows 10 build ≥ 20211; admin PowerShell)

On **this** PC first, release the disk cleanly. Otherwise the ext4 journal needs recovery on the next mount.

```powershell
wsl --unmount \\.\PHYSICALDRIVE1
```

Then safely remove it in Windows.

On the **other** PC:

```powershell
Get-Disk                      # find the disk number n of this ~931 GB drive
wsl --mount \\.\PHYSICALDRIVEn --partition 1
```

In WSL the disk appears at `/mnt/wsl/PHYSICALDRIVEnp1`. Windows itself cannot read ext4, so it must be mounted through WSL. The mount does not survive a WSL restart; run `wsl --mount` again afterwards.

## 2. Copy back, keeping the same paths (easiest, if the Linux user is `joao`)

```sh
H=/mnt/wsl/PHYSICALDRIVEnp1/preqbmc_ext/workspace_20261031
mkdir -p ~/code ~/.claude/projects
rsync -a $H/code/preqbmc/ ~/code/preqbmc/
rsync -a $H/code/preqbmc-qformat/ ~/code/preqbmc-qformat/
rsync -a $H/claude/projects/-home-joao-code-preqbmc/ ~/.claude/projects/-home-joao-code-preqbmc/
rsync -a $H/tools/esbmc-linux/ ~/esbmc-linux/
```

If the user name or paths differ, run `git -C ~/code/preqbmc worktree repair ~/code/preqbmc-qformat`. In that case Claude's history key also changes: the project folder name is the absolute repo path with `/` replaced by `-`.

## 3. Python environment

```sh
conda env create -f $H/git/conda_env_quad.yml
```

The env has an editable install pointing to `~/code/preqbmc/src`. The diagnostic driver neutralizes it by design.

## 4. Re-point the output symlink

```sh
ln -sfn /mnt/wsl/PHYSICALDRIVEnp1/preqbmc_ext/output ~/code/preqbmc/output
```

Use the actual mount name in place of `PHYSICALDRIVEnp1`.

## 5. Resume Claude

```sh
cd ~/code/preqbmc && claude --resume
```

## 6. Fallback if the working copies are damaged

```sh
git clone $H/git/preqbmc_all_branches.bundle preqbmc
cd preqbmc && git checkout branch/ssv-files && git apply $H/git/main_uncommitted.patch
git worktree add ../preqbmc-qformat feat/crown-v2-qformat
cd ../preqbmc-qformat && git apply $H/git/worktree_uncommitted.patch && tar -xzf $H/git/worktree_untracked.tar.gz
```

Do not open the same disk from two machines at once. ext4 is not a shared filesystem.
