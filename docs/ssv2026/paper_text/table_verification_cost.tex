\textit{Notes.}
Direct-C queries use compact int16 storage; CROWN certificates bind
to the int64-storage reference C. L0 denotes layer 0.
Each direct-C row is one query, with a
600\,s timeout and \texttt{5g} memory limit; layer queries check
interval containment, not classification robustness.
CROWN checks use Z3 with 60\,s and \texttt{4g} per harness.
For image 04083, layers 0--3 used 12 jobs and layer 4 used 4.
Shard wall is the sum of layer-shard wall times; summed elapsed
is the sum of individual check durations, not CPU time.
CROWN RSS is the peak aggregate across concurrent checking processes.
Finder/export time, preceding box proofs, and unsuccessful earlier
attempts are excluded. Certification assumes the binding and
composition described in the methodology.
